# felchamaa.com

Static copy of Fadi Elchamaa's website for GitHub Pages.

The first migration is generated from the current WordPress site by `.github/workflows/migrate-site.yml`. The published site lives in `docs/`, uses `felchamaa.com` as its custom domain, and keeps every currently published WordPress page URL.

Do not rerun the migration workflow after the Hostinger site is retired. Future content changes should be made directly in `docs/`.
